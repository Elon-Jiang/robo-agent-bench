# Results (suite v0.2.1)

`runs/<suite>/<scene>__<model>__s<seed>/` — one directory per scored episode, 200 total:
seeds 0–4 of spill/clear/toys/breakfast from `suite_v0.1` (unchanged scenes, identical
layouts verified by `scripts/seed_check.py`), everything else from `suite_v0.2`
(tidy_desk scene version 4).

- `episode.jsonl` — final grader record: items, score, strict success, critical errors,
  self-report and whether it was correct, seed, initial poses, `layout_sha256`.
- `run_meta.json` — turns, tokens, wall time, end reason.
- `codex_last_message.txt` — the agent's final message.

`reports/suite_v0.2.1_s0-19.{md,json}` is regenerated by
`scripts/report.py --inputs results/runs/suite_v0.1/pilot_* results/runs/suite_v0.2/pilot_*`.
